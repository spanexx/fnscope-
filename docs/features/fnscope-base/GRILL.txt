  ANSWER: run builds and tests in WSL Debian, where Rust 1.99.1 and gcc
  14.2.0 are installed. The Windows tree is the same files at the WSL mount
  path.

  working toolchain.
  SOURCE: `.reports/goal-build-fnscope.md`, line 22 ("Source: environment
  audit").

D3 [agent decision] - UI stays React.
  ANSWER: keep the supplied React/TSX component as the UI contract. Node is
  used at build time only to compile static assets; the Rust binary embeds
  those assets, so runtime needs no Node.
  WHY: the supplied UI is part of the contract and the user wants Rust at
  runtime.
  SOURCE: `.reports/goal-build-fnscope.md`, line 23 ("Source: spec section 6
  + user Rust preference").

D4 [agent decision] - Invoke semantics.
  ANSWER: execute real functions through a Node runner when available;
  otherwise return a deterministic simulated trace. Documented as such.
  WHY: the spec calls invoke optional, so a fallback is safe and testable.
  SOURCE: `.reports/goal-build-fnscope.md`, line 24 ("Source: spec section
  2B calls invoke 'optional'").

D5 [agent decision] - Watcher.
  ANSWER: poll a directory fingerprint (paths + mtimes + sizes) and rescan on
  change, instead of using a native watcher crate.
  WHY: cross-platform determinism and fewer dependencies.
  SOURCE: `.reports/goal-build-fnscope.md`, line 25.
